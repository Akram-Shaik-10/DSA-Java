## ⏱️ Complexity

### Linear Search

**Time:** `O(n)`
**Space:** `O(1)`

### Binary Search

**Time:** `O(log n)`
**Space:** `O(1)` for iterative implementation

## 🎯 Goal

Build a strong understanding of searching algorithms and recognize when **binary search can replace a linear approach** for better efficiency.
